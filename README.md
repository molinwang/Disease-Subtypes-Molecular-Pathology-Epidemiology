# Disease Subtypes and Molecular Pathological Epidemiology

Statistical methods, SAS macros, and R software developed by Dr. Molin Wang's group and collaborators for studying exposure–disease subtype associations, etiologic heterogeneity, and missing biomarker data.

## Available methods

| Method | Language | Purpose |
| --- | --- | --- |
| [Disease subtype heterogeneity](./%25subtype/) | SAS | Assess heterogeneity in exposure associations across disease subtypes. |
| [Contrast tests](./%25contrasttest/) | SAS | Test heterogeneity using estimates from separate subtype-specific analyses. |
| [Ordinal subtype trends](./%25subtype_trend/) | SAS | Test trends in exposure associations across ordered disease subtypes. |
| [Multiple-biomarker subtypes](./%25subtype_MultipleMarker/) | SAS | Assess marker-specific subtype heterogeneity while accounting for other biomarkers. |
| [Inverse probability weighting (IPW)](./%25subtype_weights/) | SAS | Estimate exposure–subtype associations and test heterogeneity when subtype data are missing. |
| [Augmented inverse probability weighting (AIPW)](./AIPW_Subtype_MultipleMarker/) | R | Analyze disease subtypes defined by multiple biomarkers, incorporating partially observed biomarker data. |
