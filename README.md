# Disease-Subtypes-Molecular-Pathology-Epidemiology

This SAS macro implements the statistical method, describred in the paper below, for assessing between-subtype heterogeneities in the exposure-subtype associations. The pdf file is the manual of the SAS macro.

Wang M, Spiegelman D, Kuchiba A, Lochhead P, Kim S, Chan AT, Poole EM, Tamimi R, Tworoger SS, Giovannucci E, Rosner B, Ogino S. Statistical methods for studying disease subtype heterogeneity. Stat Med. 2016; 35(5): 782-800. PMCID: PMC4728021
