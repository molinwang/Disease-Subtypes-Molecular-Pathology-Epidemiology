The %subtype_trend macro tests whether the exposure-subtype association has a trend across the ordinal cancer subtypes. The user runs separate Cox (for cohort studies) or conditional logistic models (for nested case-control studies) for each subtype, and then tests the heterogeneity hypothesis using the outputs from the separate models, or the user takes the estimates (and standard errors) from the literature and test the heterogeneity hypothesis. In the subtype-specific analysis, the confounders-disease associations are allowed to be different among the subtypes. The method is described in the following papers.

Wang M, Spiegelman D, Kuchiba A, Lochhead P, Kim S, Chan AT, Poole EM, Tamimi R, Tworoger SS, Giovannucci E, Rosner B, Ogino S. Statistical methods for studying disease subtype heterogeneity. Stat Med. 2016; 35(5): 782-800. PMCID: PMC4728021

Wang M, Kuchiba, A, Ogino, S. A Meta-Regression Method for Studying Etiologic Heterogeneity across Disease Subtypes Classified by Multiple Biomarkers. Am J Epid. 2015; 182(3): 263-70.
